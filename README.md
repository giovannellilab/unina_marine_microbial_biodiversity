Introductory class in the Marine Microbial Biodiversity for graduate students pursuing a Master Degree in Marine Biology and Aquaculture. The class gives a recap of basic microbiology and microbial ecology concepts and then jumps into a more in depth analysis of the major marine microbial groups and extreme marine environments on Earth. The course is designed to provide general background in marine mocrobial diversity to non-specialist coming from diverse subjects (Biology, Biotechnology, Natural Sciences, Environmental Sciences).

In the repository you may find different versions of the class relative to each academic year. I always try to improve the class material year on year, so I suggest if interested to use the latest available year.
